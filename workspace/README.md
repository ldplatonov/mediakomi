# 🏠 Медиакоми

Интерактивный симулятор оценки недвижимости. Угадайте цену квартиры по фото и описанию!

## 🎮 Как играть

1. Нажмите **«Запустить игру»**
2. Вам покажут 10 случайных квартир из базы данных
3. Двигайте бегунок и нажмите **«Оценить»**
4. Узнайте правильный ответ и заработайте баллы
5. В конце получите свой титул инвестора!

## 📊 Система баллов

| Точность | Баллы |
|----------|-------|
| ≤ 5%     | 10    |
| ≤ 10%    | 8     |
| ≤ 15%    | 6     |
| ≤ 20%    | 4     |
| ≤ 30%    | 2     |
| > 30%    | 0     |

Максимум: **100 баллов** за 10 раундов.

## 🏆 Титулы

- 🎯 **Опытный инвестор** — 75+ баллов, близки к результату
- 💰 **Щедрый инвестор** — переплачиваете за недвижимость
- 🪙 **Скряга** — экономный инвестор

## 🛠 Технологии

- **React 18** + **TypeScript**
- **Vite** — сборка
- **Tailwind CSS** — стилизация
- Мобильная версия в приоритете
- Без тяжёлых библиотек

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Режим разработки
npm run dev

# Сборка для продакшена
npm run build

# Превью продакшен-сборки
npm run preview
```
